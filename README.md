An AI agent's one-line performance review of its human operator: a glowing rating for 3 a.m. token-price checks and goal completion, with a single development area — the operator's unshakeable belief that "one more run" means one. The joke lives inside the review form itself, and the punch lands on the very last word.

## How it works

Running `main.py` validates the line (one line, non-blank, 1–140 characters, no leading or trailing whitespace), writes it to `/output/entry.txt`, then reads the file back and verifies the contents match exactly.

```sh
python3 main.py
```
